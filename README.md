# crazystairipelago

A Manual for [Crazy Stairs](https://www.roblox.com/games/2418401851/Crazy-Stairs-VR)

Now, currently you only need 5 climbs with each alignment to win, which is 60 climbs and each climb is a location, also since i didn't know how to make logic function I just went with "you need X amount of spells with this alignment to complete climb X" 

65 total locations, 60 of which are each alignments 5 climbs, and 5 extra for completing a set amount of climbs with every alignment

Each alignment (other than thief and chameleon) starts with their first spell "unlocked" as in, their first spell isn't in the .apworld and you're allowed to use it at the start. This comes out to 55 items as Muggle Has No Spells. (or well 62 including max mana increments)
Thief also has their place stairs spell unlocked by default and chameleon has nothing unlocked by default.

The alignments Gremlin, None, Necromancer, Reaver, Tutorial, Architect and Splicer all aren't included
(Gremlin is just joker 2, None is muggle 2, Architect can't climb, and the rest were added in the 4.0 update so I decided to exclude them. and tutorial is tutorial.)

Filler item is called "None's Nothing"
(not to be confused with the badge also called "None's Nothing")

**Gameplay Rules:**
- You are intended to play on Classic Tower in a private server ALONE or with other people playing in your archipelago.
- You may not morph into excluded alignments
- Everyone in your server must follow these rules, and be in your archipelago
- You are not allowed to cast ultimate spells (Spells that cost tokens)
- You may not cast or unlock spells if you haven't received their item yet
- You must use the settings to set your Max Mana Capacity to 3, then increase it by 1 with every received "Max Mana Increase" upgrade (to max out at 10 mana)

Should work with the latest manual client, and designed for Crazy Stairs 4.3.1 

# Setup

go to releases, download apworld, open file, archipelago should import apworld, download CS_Free_YAML if you DONT own spectre and chameleon, or CS_Paid_YAML if you DO own both, adjust the YAML to your liking, send YAML to host (or put in players folder if you're the host) and then just play like you would with any other manual. (Preventing yourself from using things you dont have unlocked, and checking off locations manually as you do them)
If you're using CS_Free_Yaml i advise checking off all of spectres and chameleons locations as soon as you begin as they are still included, they just have filler items.
